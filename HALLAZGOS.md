# Hallazgos de Discovery

## web

### Flujo observado

Contrato observado en el codigo; no hay un contrato acordado documentado en `docs/ENDPOINTS.md` (ese archivo no existe). `LoginComponent` envia usuario, contrasena y `client` a `http://localhost:8080/auth/login` (`web/src/app/login/login.component.ts:41`, `web/src/app/login/login.component.ts:42`, `web/src/app/login/login.component.ts:43`); si la respuesta incluye token, guarda token, usuario y preferencias en `localStorage` y navega a `/dashboard` (`web/src/app/login/login.component.ts:46`, `web/src/app/login/login.component.ts:47`, `web/src/app/login/login.component.ts:48`, `web/src/app/login/login.component.ts:49`, `web/src/app/login/login.component.ts:50`). `DashboardComponent` lee token y usuario; sin token navega a `/login` (`web/src/app/dashboard/dashboard.component.ts:36`, `web/src/app/dashboard/dashboard.component.ts:37`, `web/src/app/dashboard/dashboard.component.ts:38`, `web/src/app/dashboard/dashboard.component.ts:39`). Con token, consulta `http://localhost:8000/api/tasks?owner=...` con `Authorization: Bearer ...` (`web/src/app/dashboard/dashboard.component.ts:43`, `web/src/app/dashboard/dashboard.component.ts:44`), excluye tareas `ARCHIVED`, prepara etiquetas y ordena tareas por prioridad (`web/src/app/dashboard/dashboard.component.ts:48`, `web/src/app/dashboard/dashboard.component.ts:49`, `web/src/app/dashboard/dashboard.component.ts:50`, `web/src/app/dashboard/dashboard.component.ts:54`). Cerrar sesion elimina token y usuario, conserva preferencias y navega a `/login` (`web/src/app/dashboard/dashboard.component.ts:75`, `web/src/app/dashboard/dashboard.component.ts:76`, `web/src/app/dashboard/dashboard.component.ts:77`, `web/src/app/dashboard/dashboard.component.ts:78`). No se verifico este flujo en ejecucion.

### Componentes y dependencias observados

`LoginComponent` gestiona formulario, llamada HTTP, estado de sesion y navegacion (`web/src/app/login/login.component.ts:31`, `web/src/app/login/login.component.ts:41`, `web/src/app/login/login.component.ts:47`, `web/src/app/login/login.component.ts:50`). `DashboardComponent` gestiona consulta y presentacion de tareas y cierre de sesion (`web/src/app/dashboard/dashboard.component.ts:35`, `web/src/app/dashboard/dashboard.component.ts:43`, `web/src/app/dashboard/dashboard.component.ts:75`). `formatTaskLabel` formatea prioridad y propietario (`web/src/app/utils/legacy-format.ts:1`). El manifiesto declara `axios` 0.31.0 y `lodash` 4.17.21 (`web/package.json:19`, `web/package.json:20`); no se ejecuto auditoria de dependencias.

### Validacion pendiente

Para H-WEB-01, H-WEB-02, H-WEB-03, H-WEB-04, H-WEB-06 y H-WEB-07 se ejecutaron pruebas; resultados y cobertura estan registrados en `PLAN.md`. El build paso tras los cambios de producto. H-WEB-08 permanece Pendiente y no se oculta con una prueba que acepte la respuesta incompleta.
